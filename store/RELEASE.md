# Релиз Dead Zone в Google Play — пошагово

## 0. Перед сборкой (в Godot)
1. Плагины включены: Project → Project Settings → Plugins → **AdMob**, **Dead Zone Export**, **NotificationScheduler**.
2. Project → Install Android Build Template (если ещё не ставил или после обновления Godot).
3. Project → Export → **Android**:
   - Export Format: **Android App Bundle (AAB)** (уже выставлено).
   - Version → Code: **1** (каждая новая загрузка в Play: +1), Name: **1.0.0**.
   - Keystore → Release: `~/keys/deadzone-release.keystore`, пользователь и пароль. Ключ хранить в двух местах, без него обновления выпустить нельзя.
   - Target SDK: оставить пустым (значение Godot по умолчанию) или не ниже требования Play на дату загрузки.
   - **Export With Debug — выключить** (иначе тестовая реклама и F9/F10).
4. Export Project → `export/DeadZone.aab`.
5. Перед загрузкой поставить сборку на свой телефон (Export → APK debug или через Play внутреннее тестирование) и пройти: запуск, согласие на рекламу, обучение, миссия, убежище, реклама за награду, напоминание.

### Безопасность данных (данные собирает Google AdMob)
- Собирает или передаёт данные: **Да**. Все данные шифруются при передаче: **Да**.
- Способ удалить данные: аккаунтов нет; указать, что данные хранятся на устройстве и удаляются вместе с приложением (вопрос «можно запросить удаление» — **Нет**, либо ссылка на политику).
- Типы данных (сбор и передача, цель — **Реклама или маркетинг**, **Аналитика**, **Предотвращение мошенничества**; обязательные, не эфемерные):
  - Местоположение → **Приблизительное местоположение**;
  - Действия в приложении → **Взаимодействие с приложением**;
  - Сведения о приложении и производительности → **Журналы сбоев**, **Диагностика**;
  - Идентификаторы устройства и другие идентификаторы → **Идентификаторы устройства или другие идентификаторы**.

## 4. Страница в магазине (Рост → Страница в магазине → Основная)
- Тексты: `store/listing.md` (русский + английский — добавить перевод «English (United States)»).
- Значок 512×512: `icon.png`, уменьшенный до 512.
- Главное изображение 1024×500: `store/feature_graphic.png`.
- Скриншоты телефона: `store/screenshots/` (7 шт., 1920×1080). Лучше добавить 1–2 снятых на телефоне.
- Категория: Игры → **Экшен**. Контакты: эл. почта (обязательно), сайт — Telegram.

## 5. Закрытое тестирование (обязательно для новых личных аккаунтов)
1. Тестирование → **Закрытое тестирование** → создать трек → загрузить `DeadZone.aab`.
2. Тестировщики: список email (можно тот же, что у Stack Tower), **не меньше 12 человек**.
3. Разослать ссылку-приглашение: каждый принимает, ставит игру и **не удаляет 14 дней**.
4. Через 14 дней: Панель управления → **Подать заявку на доступ к рабочей версии** (ответы о тестировании: сколько людей, что проверяли, что исправили).

## 6. Рабочая версия
После одобрения: Рабочая версия → Создать выпуск → тот же или новый AAB (code +1) → страны → **поэтапное развёртывание 20%** → через 2–3 дня 100%, если нет сбоев (Мониторинг → Android Vitals).

## 7. AdMob после публикации
AdMob → Приложения → Dead Zone → **Привязать к Google Play** (когда игра появится в магазине). Проверить, что включено окно согласия (Конфиденциальность и сообщения → GDPR) и подключён app-ads.txt (если есть сайт).

## 8. Обновления
Каждое обновление: version/code +1, version/name (1.0.1, 1.1.0…), AAB → тот же трек.
